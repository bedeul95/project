# ATLAS Quant Mac · 1.3.0

맥미니에서 한국·미국 기업의 시세/분기 재무를 수집하고 기업·안정성 70점 + 기술 30점으로 분석하는 로컬 웹 프로그램입니다. **이번 단계는 조회·분석 우선**이며 계좌·주문은 기본 서버와 화면에서 비활성입니다.

## 먼저 실행하기

1. ZIP 압축을 풀어 폴더를 보관합니다.
2. 조회·예약 분석에는 **Python 3.9+와 Node.js 18+**가 필요합니다. 추가 pip/npm 패키지는 없습니다. Python: https://www.python.org/downloads/macos/ · Node: https://nodejs.org/en/download
3. `서버로실행.command`를 실행합니다. `http://127.0.0.1:8765`가 열립니다. Finder에서 실행이 제한되면 터미널에 `bash `를 입력하고 파일을 끌어놓아 실행하세요.
4. **조회·자동분석**에서 Twelve Data 데이터 API 키를 입력하고 설정을 저장합니다. 증권계좌·증권사 키는 입력하지 않습니다. 키를 채팅으로 보내지 마세요.
5. 기본 표본은 `KR,005930,XKRX`와 `US,AAPL,XNAS`입니다. **지금 양 시장 분석 → 상태·결과 새로고침**으로 권한과 결과를 확인합니다.
6. **기업·거래량 화면에서 보기**로 수집 자료를 스크리너/거래량/기업 상세에 적용합니다. 분석 JSON을 다운로드해 보관할 수 있습니다.

키가 없는 상태에서는 가상 기업의 합성 예제만 표시합니다. 실제 키/구독 없이 라이브 데이터가 연결됐다고 표시하지 않습니다. Python 없이 `시작.html`을 열면 기존 예제·JSON 입력 분석은 가능하지만 API 수집/예약은 동작하지 않습니다. Node가 없으면 수집 자료는 저장할 수 있으나 서버 점수 계산은 미완료 상태로 표시됩니다.

데이터 제공사 무료 계정이 모든 한국·재무 자료를 제공하지 않습니다. 한국 EOD·재무·통계·12분기 이력은 요금제/종목별 권한을 확인해야 합니다. 최소 표본에서 실제 응답을 확인한 뒤 계약하세요. 회사나 외부 앱의 표시·배포는 별도 이용권한 검토가 필요합니다. 자세한 비교와 공식 링크는 **API비교_수집설계.md**에 있습니다.

## 매일 자동 실행

기본 한국시간 08:30 미국(화~토), 18:30 한국(월~금)입니다. 설정에서 하루 1회 저녁 양 시장으로 바꿀 수 있습니다. 매일 1~2회는 배치 횟수이며 종목/조회 항목별 HTTP 요청이 여러 개 발생합니다.

처음 설정 후 수동 서버를 Ctrl+C로 종료하고 **자동분석설치.command**를 실행하세요. macOS 로그인 LaunchAgent로 서버가 시작됩니다. 이후 브라우저에서 http://127.0.0.1:8765 를 열어 결과를 확인합니다. 설치한 폴더를 옮기지 마세요. 해제는 **자동분석해제.command**입니다. 키/자료를 지우지 않고 자동 시작만 해제합니다.

맥이 잠들거나 종료되면 분석이 실행되지 않습니다. 설치 프로그램이 절전 설정을 바꾸거나 맥을 깨우지 않습니다. 예약은 서버가 실행될 때 검사하며 3시간 이내 지난 슬롯만 한 번 보충합니다. 같은 날짜/슬롯과 같은 runtime 폴더의 서버 중복 실행을 막습니다. 실패·재시작한 배치를 자동으로 무한 재시도하지 않습니다. 필요할 때 ‘지금 분석’을 실행하세요.

초기/재무 캐시 만료 수집은 종목당 약 381 credits, 캐시 유효 시 일봉 1 credit을 예상합니다. 기본 재무 캐시 24시간, 분당500/실행당1,500/일3,000 한도입니다. 기본 설정의 최초 수집은 최대 약 3개 종목 수준으로 제한될 수 있습니다. 요금제의 크레딧과 종목 수에 맞게 조정하세요. 한도를 높이는 것만으로 유료 권한이 생기지는 않습니다.

기본 후보 조건은 총점70/기업45/기술12 이상입니다. 재무 누락·적자·자본잠식·현금흐름·유동성·과열·자료 이상 제한을 점수보다 먼저 적용합니다. 기술에는 80거래일이 필요합니다. 예약 분석은 기본 평가 설정을 사용합니다. 브라우저 연구실의 변경은 자동으로 서버 예약에 동기화되지 않으며, 서버 보고서에 사용한 설정이 포함됩니다.

지정 종목 1~200개의 비교 분석이며 전종목 스캐너가 아닙니다. 같은 업종 평가 가능 종목이 5개 미만이면 목록의 시장 내 비교로 대체합니다. 몇 종목만 넣은 상대 순위를 전체 시장의 저평가 순위로 해석하지 마세요.

## 데이터 기준·실패 처리

- 완료된 일봉만 사용하고 실제 가격일·조회 관측일·재무 수집 시각을 보존합니다. 휴장 캘린더 API는 미구현이며 서머타임/주말 기준 추정과 실제 반환 날짜를 표시합니다.
- 코드/MIC/통화/분기 기준·중복 날짜·OHLCV 범위를 검사합니다. 최근 분할 이전 일봉은 제거해 분할 경계의 가격/거래량 오해를 피합니다. 분할 뒤 80일 전은 기술 보류입니다.
- 4개 연속 분기를 합쳐 TTM을 만들고 전년 TTM에는 8개가 필요합니다. 누락을 임의의 0이나 연환산으로 채우지 않습니다. 분기 현금흐름은 제공자의 분기 정규화 기준을 사용합니다.
- 주식수·부채·자본·순이익 조정과 투하자본은 표준 제공 자료의 단순 추정입니다. 필드가 없으면 일부 지표/후보가 제한됩니다. 정밀 공시 원자료 대사는 미구현입니다.
- 실제 과거 공시/정정 시점을 확인하지 못한 API 재무는 수집 관측일 기준입니다. 공시일은 ‘미확인’으로 표시하고 **이 자료의 과거 백테스트는 차단**합니다.
- 전부 실패하면 기존 결과를 유지합니다. 일부 실패하면 해당 배치 시장의 성공 종목만 교체하며 미수집 목록을 표시합니다. 다른 시장의 이전 자료는 원래 시각을 유지하고 7일 초과 가격 지연은 후보 제한합니다.
- 분석 보고서·수집 기록 각 최근30개 보관. 자동매매, 주문·잔고·환전, 뉴스/컨센서스/산업 전망, 토큰/실제 배당은 이번 버전 기능이 아닙니다.

## 저장·백업

서버 키는 `runtime/research/data-config.json`(파일 권한600)에 저장하며 암호화 저장은 아닙니다. 키와 runtime 폴더를 공유하지 마세요. 서버 API는 loopback127.0.0.1/Host/Origin/세션 확인을 사용합니다. 외부 데이터 요청은 고정 Twelve Data 조회 GET 경로입니다. 브라우저/분석 JSON에 키를 저장하지 않으며 배포 ZIP에 runtime을 포함하지 않습니다.

서버 최신 자료는 `runtime/research/latest.json`, 보고서는 `runtime/research/reports/`, 재무 캐시는 `runtime/research/cache/`입니다. 분석 JSON과 전체 브라우저 JSON 백업은 별개입니다. 전체 백업에는 예제/입력 자료·연구 설정·관심 목록·모의 계좌·분배 가정이 포함됩니다. 정기적으로 다운로드하세요.

API 자료를 기존 화면에 적용할 때 모의 계좌의 종목 ID가 맞으면 유지하고, 맞지 않는 보유/주문이 있으면 초기화를 확인합니다. JSON 파일 수동 가져오기는 기존처럼 자료/모의 계좌를 교체합니다. 파일 URL·서버 URL·브라우저/포트는 별도 로컬 저장 공간입니다.

## 기존 연구 기능과 한계

JSON 입력(최대12MiB, 200종목, 종목당25~2500일봉)을 통한 스크리너·거래량·기업 상세·관심 목록·CSV·모의 매매·분배 가정이 유지됩니다. 예제데이터.json은 가상 기업20개의 합성 자료이며 실제 시세/수익이 아닙니다.

공시 시점이 검증된 별도 JSON의 백테스트는 전일 신호/당일 종가, 정수 수량·현금 한도·편도 비용을 사용하는 연구 도구입니다. 배당·세금·환전·호가·부분체결·시장충격·비동일 거래일/상장폐지 처리·업종 한도 등은 미반영입니다. 데이터의 공개 시점 정확성은 사용자가 확인해야 합니다. 점수/필터는 검증 전 가설이며 손실 방지·수익성을 보장하지 않습니다.

## 개발·검증

```bash
python3 build.py
node --test tests/*.test.cjs
python3 -m unittest discover -s tests -p 'test_*.py'
```

Python stdlib와 Node 내장 기능만 사용합니다. 1.3.0의 테스트·미검증 범위는 TESTING.md에 있습니다. 실제 API 키가 없어 제공자 인증/실제 종목 응답을 검증하지 못했고, 실제 맥미니·Safari 장비 검사도 수행하지 못했습니다.
