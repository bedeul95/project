# Project03 — KR/US × 3개 전략 TOP 10 산출 명세

- 문서일: 2026-10-14
- 상태: 2026-10-15 실행 소스/6개 순위 계산·API·UI·MCP 구현. 실제 최신 전체시장 feed/시세는 미검증. 구현 계약은 [UNIVERSE](../guide/UNIVERSE.md), 검증은 [TESTING](../../TESTING.md) 참조.
- 기준 버전: 원본 패키지 1.4.0 / 기존 engine 1.3.0 (버전 혼용 표시 유지)
- 구현 선행조건: [데이터/검증 계약](DATA_PIPELINE_AND_VALIDATION.md), [개발 로드맵](ROADMAP.md)
- 참고 후보: [기존 답변의 미검증 후보](../reference/PROVISIONAL_CANDIDATES_20261014.md)

## 목표

한국(KOSPI+KOSDAQ)과 미국(NYSE+NASDAQ 및 명시적으로 지원하는 상장시장) 각각에 대해 아래 3종의 TOP 10 목록을 매 분석 시각 산출한다. 총 6개 목록 × 최대 10개 = 최대 60개 **랭킹 슬롯**이며 동일 종목의 목록 간 중복은 허용한다.

1. **저평가 TOP 10**: 가치·수익성·재무 건전성·성장의 재무 평가 우선.
2. **기존 보조지표 TOP 10**: 1.3.0 엔진 기술점수 기준; 기존 70/30 총점과 나란히 표시.
3. **첨부 알파스퀘어 기반 TOP 10**: 사용자가 첨부한 종목필터 화면의 10개 전략을 자체 정의한 근사 규칙으로 구현. **알파스퀘어의 내부 독점 수식과 동일하다고 주장하지 않는다.**

종목명·거래소·정규화된 종목코드·시장·점수(서로 다른 척도 구분)·랭킹·선정 근거/조건 충족 날짜·위험도·데이터 갱신 시각·수집 출처·제외 사유·신뢰상태를 기록한다.

## 유니버스 및 순위 공통 규칙

- 지정 관심종목만이 아닌 각 시장의 **전체 활성 상장 보통주 유니버스**를 먼저 확보한다. 전체 유니버스를 확보하지 못하면 결과 제목을 '전체시장 TOP 10'으로 쓰지 않고 '표본 내 참고 TOP 10'으로 표시한다.
- KRX 거래정지/매매정지/관리종목, 상장폐지 확정 또는 진행 중 거래제한 등 공개 상태를 기준으로 제외한다. 미국은 해당 거래소의 거래정지/상장폐지·중대한 상장요건 미충족 등 대응 가능한 상태를 별도로 확인한다(한국식 '관리종목'과 일대일 대응시키지 않음).
- ETF/ETN/우선주/스팩/펀드/비운영 지주상품 등은 초기 보통주 전용 범위에서 제외하고 ADR·REIT·금융업·보험업은 분리된 업종 비교가 없으면 평가보류로 표시한다. 정책 변경 시 적용 대상과 결과를 버전 관리한다.
- 분기재무/TTM 보고기간, 실제 공시 공개일, 수정공시 시점, 종목의 상장·합병·액면분할/주식분할 이력을 보존한다. 미래 정보 누출 방지.
- 최근 **완료된 거래일**의 분할·배당 등 기업행동을 처리한 가격 시계열과 실제 거래량·거래대금을 사용. 시차/휴장(KST/미 동부)·데이터 지연 정책을 명시한다.
- 값이 없으면 0점으로 치환하지 않고 **평가보류/데이터부족**으로 처리한다. 거래량/재무 조회 오류가 여러 종목에 발생했을 때 성공 종목만으로 무심코 '전체시장 10위'를 선언하지 않는다.
- 후보가 10개 미만이면 있는 만큼만 표시하고 '10종목 미충족' 사유를 남긴다.
- 동점 정렬: 점수 ↓ → 데이터 충족률 ↓ → 적정 유동성 ↑ → 변동성 위험 ↓ → 시장+코드 사전순. 순위 재현성을 보장한다.

## 공통 점수체계와 하위순위 정의

기존 제품의 **기업 70 + 기술 30 = 총점 100**을 유지한다.

| 기업 70 | 점수 | 예시 확인 항목 |
| --- | ---: | --- |
| 가치 | 20 | 업종 대비 PER/PBR/FCF yield 및 영업손실 여부 |
| 수익성/질 | 20 | ROE/ROIC/마진의 지속성, 현금흐름 |
| 재무안정성 | 20 | 순차입금·이자보상·현금/유동성(업종별 모델) |
| 성장 | 10 | 관측 가능한 매출·영업이익 TTM 성장 |

| 기술 30 | 점수 | 예시 확인 항목 |
| --- | ---: | --- |
| 거래량·횡보 | 10 | 거래량 변화, 변동폭·가격 응축 |
| 추세 | 8 | 이동평균 기울기·정렬·가격 위치 |
| RSI/MACD | 6 | 과열/과매도와 추세 교차 |
| ATR/볼린저 | 6 | 변동성/밴드 위치 및 리스크 |

**저평가 목록:** '기업 70점' 우선 정렬(표시용 `value_score_100 = fundamental_score_70 / 70 * 100`). 재무 안전성 최소 조건과 업종별 적합성을 통과해야 한다. 기존 `total_score_100`은 별도 열로 병기하되 이를 가치점수라고 부르지 않는다. PER가 낮다는 사실만으로 자동 상위권 처리하지 않는다.

**기존 기술지표 목록:** 기존 엔진 산식의 `technical_score_30` 우선 정렬(표시용 `technical_score_100 = technical_score_30 / 30 * 100`). 충분한 완료 일봉·거래량·유동성을 선행 검사한다. `fundamental_score_70`와 `total_score_100`은 참고값이며 기업 부실 시 **위험/평가보류**를 명확히 한다.

**첨부 전략 목록:** 아래 전략 충족/강도 신호별 기본 가중치 **각 10점, 합계 최대 100점**. 종목에 해당하지 않는 전략은 가점 없음. 미수집으로 판별 불가한 신호를 '미충족'으로 채점해서는 안 되며, 최소 1개 유효 신호·충분한 공통 자료를 요구한다. 같은 가격 이벤트에서 여러 신호가 겹치는 상관 위험을 별도 경고한다. 신호가 0개거나 유효데이터 부족이면 '추천' 제외.

## 첨부 스크린샷 기반 전략 10개 (초기 규칙; 조정 가능한 설계값)

| 전략 | 제안 구현 | 최소 데이터·주의 |
| --- | --- | --- |
| 상승 추세 눌림목 포착 | SMA20>SMA60, SMA60 상승 기울기, 종가가 SMA20 ±3% 범위에 근접하고 급락이 아닐 것 | 80개 이상 완료 일봉; '눌림목'은 추세 유지 확인 |
| 신고가 돌파 모멘텀 | 당일 종가가 직전 252거래일 최고 종가를 상향 돌파, 거래대금/거래량 20일 평균 대비 확대 | 기업행동 보정된 253개 이상 완료 일봉; 장중 돌파만으로 확정하지 않음 |
| 정배열 추세 지속 | SMA5>SMA20>SMA60>SMA120, SMA20 기울기 양수 | 120개 이상 거래일 |
| 골든크로스 발생 | SMA5가 SMA20을 당일 상향 교차, 종가·거래량 조건 확인 | SMA5/20 규칙 초안; 화면상 정확한 기간은 사용자가 조정 가능 |
| 거래대금 급증 포착 | 원화/달러 단위 당일 거래대금이 과거 20거래일 평균의 2배 이상, 가격 상승 동반 | 시장별 통화 혼합 금지·이상 체결값 확인 |
| 단기 상승 모멘텀 | 최근 5거래일 수익률 양수·상승폭/거래량 증가가 병행 | 급등·갭 과열 시 위험도 상향 |
| RSI 과매도 반등 | Wilder RSI14가 30 이하에서 상향 돌파하며 가격 회복 확인 | 'RSI <30'과 '반등 신호'를 구분 |
| MACD 추세 전환 | EMA(12)-EMA(26)의 MACD가 signal EMA9를 상향 돌파하고 가격이 주요 이동평균을 회복 | look-ahead 없는 완료 일봉 |
| 저평가 우량주 | 업종 비교 PER/PBR + ROE/영업이익·현금흐름 긍정 | 금융업 모델 별도; 유효한 TTM 필수 |
| 배당주 | 확정 배당 내역 기준 수익률과 지급 지속성·현금흐름 검증 | 예상/확정 배당 구분, 배당락과 통화 처리 |

*초기 임계값(±3%, 2배, RSI30, 이동평균 기간 등)은 분석 설계용 기본값이며 과거 데이터 검증을 거친 공식 최적값이 아니다. 전략별 조건 구성값 및 변경 이력을 저장하고 시장·업종별 백테스트에서 과적합을 방지한다.*

## 위험도 및 선정 근거

- 위험도는 **낮음/보통/높음/평가불가**. 종목별 ATR/종가, 최근 최대낙폭, 거래대금·스프레드, 재무부담, 이벤트/공시 리스크를 개별로 기록 후 규칙 기반 집계한다. 검증된 실측값 없이 주관적으로 위험등급을 할당하지 않는다.
- 순위 근거는 `feature_name`, `observed_value`, `rule_threshold`, `period`, `as_of`, `source`를 함께 반환하여 'RSI 반등' 등 문구가 실제 계산값과 대응되게 한다.
- **단순 후보·외부 서비스 점수·Project03 계산 점수를 UI에서 다른 배지/컬럼으로 표시**한다.

## 결과 인터페이스 제안

`GET /api/research/rankings?market=KR|US&strategy=value|legacy_technical|alpha_filters&as_of=YYYY-MM-DD`

응답의 필수 필드(API 구현 완료 · 세션 필요):
`status` = verified | partial | unavailable, `market`, `strategy`, `as_of_market_close`, `generated_at`, `universe_count`, `eligible_count`, `coverage_rate`, `exclude_reasons`, `algorithm_version`, `source_provenance`, `rows[0..9]`.
각 row: `rank`, `name`, `symbol`, `exchange`, `score`, `score_scale`, `fundamental_70`, `technical_30`, `total_100`, `signal_details`, `risk_level`, `risk_reasons`, `data_as_of`.

데이터 부족/유효 유니버스 불완전: HTTP 응답 성공이어도 `status=partial`; 표제에 '전체시장 TOP 10'을 붙이지 않는다. 이전 성공 데이터는 덮어쓰지 않고 보존+오래됨을 명시한다.

## 검수 완료 조건

1. 한국·미국 각각 전 종목 유니버스 건수·제외 건수·데이터 정상 수집 비율 기록.
2. 6개 목록의 독립 점수 범위·중복 허용·재현성 및 타임스탬프 일치 확인.
3. RSI/MACD·SMA·TTM 테스트 벡터와 시장 휴장/분할/공시 정정·이상 거래량 테스트 통과.
4. 관리종목·거래정지·폐지·권한없음·API 차단 종목은 결과에 없는지 점검.
5. 모바일/데스크톱에서 '실측 데이터'와 '미검증 후보' 오인 불가.
6. 매일 1~2회 예약 분석은 공급자 호출 총 1~2회가 아님. API 비용/예산 제한 및 비밀값 미노출 검증.
7. 계좌/실거래 주문 및 코인 발행·판매·배당 실행은 이 기능에 포함되지 않음(별도 승인·법률 검토). 

## 1.5.0 구현 게이트/차이

verified 최소수치는100%로 정했습니다. 금융업·신규상장·미확보자료를 포함한 유니버스가 완전평가에 도달하지 않으면 보수적으로 partial입니다. 판별불가 알파 신호가 있으면 확인된 신호점수는 하한이고 상한/unknown_count를 별도로 표시합니다. 기술 목록의 기업 자료 누락은 null/위험평가불가입니다. 저평가는100% 구성자료와200일 이내 결산을 요구합니다. 값의 업종 비교 fallback은 기존 엔진 동작을 보존하고 근거에 표시합니다. 실측 거래대금 미제공시 종가×거래량 근사 표시. 실제 배당/기업행동·거래상태 feed 연결은 미완료입니다.
