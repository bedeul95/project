## 처리 파이프라인

1. **증권 마스터 수집**: 시장·거래소·통일된 symbol·식별자(한국 종목코드/미국 FIGI/CIK 등)·상장/거래 상태·업종·통화/시간대 기록.
2. **초기 제외**: 상태가 검증되지 않은 경우 추천보류; 정지/관리/폐지 및 제외 상품유형은 별도 사유 기록.
3. **시세 수집**: 마감된 거래일만, OHLCV·거래대금·조정계수·split/dividend, 원자료 시간/호출시간과 데이터 소스 저장. 데이터 유효성(0/음수/역순/중복) 검증.
4. **재무 수집**: 실제 공시 관측일 및 수정 이력, 4개 연속 분기 TTM, 동기간 비교 시 8분기 이상, 기업행동·주식수/통화 단위 일치.
5. **지표 계산**: 기존 기업70+기술30 로직의 동일 엔진 실행; 새 알파전략 10개는 독립 모듈로 계산해 세 목록을 별도로 만듦.
6. **필터 재확인**: 종목 랭킹 발행 직전 유니버스/거래정지 상태를 최신으로 재확인.
7. **랭킹 저장/게시**: as-of·호출 예산·수집 커버리지와 함께 원자적으로 결과 교체. 6개 조합마다 성공/부분 성공/실패를 구분.
8. **검증 로그/리포트**: 성공 종목 수/누락원인·출처·API 비용·알고리즘 버전·생성 시각. 비밀값/PII/거래계좌정보 로그 금지.

## 커버리지 게이트와 검증 상태

- **verified**: 해당 시장 유니버스/상장상태와 필수 시세/재무가 계약된 기준을 만족하며 전체시장 커버리지 목표를 달성한 경우. 최소 기준은 코드 배포 이전에 명시적 수치로 확정·테스트한다.
- **partial**: 일부 종목 실패/유니버스 불완전/API 월간 한도·구독권 제한·자료 최신성 미달. 표제는 '조회 성공 표본 TOP 10 (전체시장 순위 아님)'.
- **unavailable**: 정상 결과를 낼 증거 부족. 이전 성공 결과가 있다면 '과거 결과(기준일 표시)'로 분리.
- **unverified_example**: 대화/외부 스크리너에서 가져온 값; 자동분석 결과와 합치지 않는다.

메타데이터 `universe_count`, `excluded_count_by_reason`, `eligible_count`, `prices_covered_count`, `fundamentals_covered_count`, `fully_scored_count`, `last_market_date`, `source_snapshots`, `is_full_market_ranking` 필수.

## 운영 정책

- 기본 배치 시간: KST 08:30 (미국장 완료 데이터 확인용, 화~토), 18:30 (한국장 완료 데이터 확인용, 월~금). 실거래 달력과 시간대 변경(DST)에 따라 완료 시각을 반드시 점검.
- 기존 공급자 별 request budget·일자별 크레딧·지수 백오프(429/5xx)·캐시 갱신·중복 slot 잠금 보존. **'하루 1~2회 배치'는 'API 요청 1~2회'가 아니다.**
- 서버 실패 시 직전 검증 데이터 보관, 새 일시를 이전 일시에 덮어쓰지 않음.
- 127.0.0.1 로컬 서버 바인딩·Host/Origin/session 방어 유지, runtime API키 권한0600, 로그/스크린샷/커밋 키 노출 금지.
- macOS LaunchAgent는 절전 중 실행 보증을 하지 않는다. 절전 복귀 후 slot 보충/중복 방지 검사.
- 추천/알림/리서치만 수행. KIS의 계좌/주문 엔드포인트와 코인 발행·배당·투자자 데이터는 연결하지 않는다.

## 단계별 적용 위치(원본 소스 이관 후)

- `market_data.py`: 종목 전체 마스터·시세/재무 데이터 수집·캐시·배치 상태·커버리지.
- `src/engine.js`: 기존70/30 계산/평가보류 유지, 새 모듈로 10개 알파 필터 도입.
- `analyze.cjs`: 동일 엔진의 서버 실행 브리지에서 6개 목록 산출(로직 복제 금지).
- `src/read-ui.js`, `src/app.js`: 시장/전략 탭, 출처/데이터신선도/위험/종목코드 표기.
- `mcp_server.py`: 저장된 랭킹 **읽기 전용** 노출. 주문·API 조회 실행 도구 추가 금지.
- `tests/`: 수학 지표, 원자료 시점, 종목상태, 마켓별 유니버스 회귀.
