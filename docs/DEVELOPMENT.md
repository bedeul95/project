# project 개발 재개 안내

## 현재 상태

저장소 https://github.com/bedeul95/project, 공개, 문서 초기화 후 main.
현재는 문서 5개만 있고 서비스 목적·런타임·API·DB·실행 환경은 정해지지 않았다.
점검일 2026-10-14. 기존 저장소가 빈 상태였으므로 기존 코드 테스트·배포 이력도 확인할 수 없다.

## 재개 절차

1. 현재 branch/HEAD·파일·미커밋 변경을 확인한다.
2. README/PROJECTS/AGENTS를 읽고 실제로 개발하려는 목적과 기능을 사용자 지시에서 확인한다.
3. 기술/실행 환경·상태 보존·설정·API/화면의 최소 범위를 정한다.
4. 실제 코드를 추가한 뒤 CODE_STRUCTURE와 실행/검증 가이드를 갱신한다.

다른 프로젝트 코드를 이름만 보고 복사하지 않는다. 프로젝트4 저장소를 이 저장소라고 임의 대응시키지 않는다.
인증정보·운영 데이터는 문서에 기록하지 않는다. 현재 실행/빌드/테스트 명령은 없다.
