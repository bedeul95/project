# Project03 — 퀀트 조회·분석 개요

이번 정리에서03 번호를 배정했다. 현재 공개 저장소에는 문서만 있으며 원본 ZIP의 실행 코드는 이관 대기다.
원본 패키지1.4.0, MCP1.4.0, 기존 README/계산 엔진1.3.0을 구분한다.
제품은 지정 KR/US 종목의 시세/재무 조회·기업70+기술30 점수·자료 상태/후보 제외 이유를 제공한다.
주식 조회·분석이 현재 범위이며 계좌/주문은 기본 서버/화면에서 비활성이다.
Twelve Data 실제 키/구독·응답·맥미니 LaunchAgent는 이번 구조 분석에서 검증하지 않았다.
