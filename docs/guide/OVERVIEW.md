# Project03 개요

2026-10-15 기준 실행 소스 이관과6개 TOP10 리서치 기능이 구현되었습니다. 기본 조회 제품은 계좌 없이 Twelve Data 지정 목록 또는 외부 공식 거래상태 마스터를 분석합니다. 기업70+기술30 산식은 원본과 동일하며 근사전략10개를 별도 점수로 제공합니다.

실제 키/구독·공식 전 시장 상태 feed는 이 환경에서 연결하지 않았습니다. default 데이터는 합성 예제이며 실제 주가·실측 순위로 표시하지 않습니다. 외부 정규화 데이터 입력도 가능하며 status unknown/자료 누락이면 추천 보류합니다. 알파스퀘어 독점 수식과 동일하다고 주장하지 않습니다.
